# Acceptance Criteria

## User Story 1: Search Gyms
Given the user is on the Gym Search page
When the user enters a location and clicks Search
Then the system displays gyms that match the selected location.

## User Story 2: View Gym Details
Given the user has selected a gym
When the gym detail page is opened
Then the system displays the gym information.

## User Story 3: Browse Activities
Given the user is on the Activities page
When the page loads
Then the system displays available indoor and outdoor activities.
