# Requirements Specification

## Functional Requirements

### FR-01 View Gym List
The system shall display a list of available gyms.

### FR-02 Search Gym
The system shall allow users to search for gyms by location.

### FR-03 View Gym Details
The system shall display gym name, address, opening hours, membership fee, and available facilities.

### FR-04 Browse Activities
The system shall display indoor and outdoor activities.

### FR-05 View Workout Plans
The system shall display beginner-friendly workout plans.

### FR-06 Equipment Guide
The system shall provide instructions for using gym equipment.

### FR-07 Filter Activities
The system shall allow users to filter activities by budget, fitness level, and available time.
